# 🌿 Sabzineh | Plant Shop

**Sabzineh** is a Persian, RTL (Right-to-Left) online plant shop website designed to provide a simple and user-friendly shopping experience for indoor plants.

The project is built with HTML, CSS, and JavaScript and includes a product catalog, shopping cart, management dashboard, and a simple customer messaging interface.

## ✨ Features

- 🌱 **Homepage:** A welcoming landing page introducing the plant shop.
- 🪴 **Product Catalog:** Browse available plants and view product information.
- 🛒 **Shopping Cart:** Add products to the cart and review selected items.
- 📊 **Admin Dashboard:** View sales statistics, revenue, average order value, and order details.
- 🔐 **Admin Login:** A basic demonstration login for accessing the management panel.
- 💬 **Customer Messaging:** View sample customer conversations and send messages through the interface.
- 🎨 **Responsive Design:** A clean, nature-inspired interface designed for a pleasant browsing experience.
- 🇮🇷 **Persian Language Support:** Persian content and right-to-left layout.

## 🛠️ Technologies Used

- **Python:** Generates the HTML file and opens it in a web browser.
- **HTML5:** Structures the website.
- **CSS3:** Handles styling and layout.
- **JavaScript:** Implements interactive website features.
- **Web Browser:** Displays and runs the website.

## 🚀 Getting Started

### Prerequisites

- Python 3
- A modern web browser, such as Google Chrome

### Installation and Usage

1. Download or clone this repository.
2. Open the project folder.
3. Run the Python script or execute the notebook cell.
4. The script generates a file named `sabzineh.html`.
5. Open the generated HTML file in your browser to explore the website.

## ⚠️ Project Limitations

- The project currently runs as a front-end demonstration.
- Product, order, customer, and messaging data are handled in JavaScript.
- A persistent database and back-end API are not implemented in the provided notebook.
- The admin login is not secure authentication.
- The Python script uses Windows-specific Chrome paths as part of its browser-launching logic, with a default browser fallback.
